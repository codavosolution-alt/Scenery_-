# مصفوفة متطلبات Scenery 2.0

العمودان التاريخيان يوضحان أصل المتطلب وقبوله في 1.1. معيار 2.0 وحالته هما المرجع الحالي عند الاختلاف. جميع حالات القبول مخططة. FE يحاكي التفاعل في G2/G3، وBE يقيس التشغيل عند G5 بعد اعتماد G3 وإذن G4. كل قرار ووثيقته ودليل التحقق مفصلة في [تتبع الإضافات D01–D60](TRACEABILITY_DELTA.md). [مراجعة المصادر](SRS_REVIEW.md)
