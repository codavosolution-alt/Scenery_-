## مصفوفة التفويض المفاهيمية

| الفعل | زائر | Owner | Staff | sysadmin |
|---|---|---|---|---|
| قراءة المنشور والبحث والمشاركة والاستفسار | مسموح ضمن المنشور والنماذج | كزائر أو عبر الإدارة | كزائر أو عبر حقه | كزائر أو عبر حقه |
| عرض/إنشاء/تعديل/نشر/حذف المحتوى والأسعار | لا | إدارة نطاق المصنع | يمنح كل فعل وقسم بوضوح | أعمال دعم ضمن الحوكمة المتفق عليها |
| إسناد وتعديل حالة وملاحظات | لا | جميع الطلبات وإعادة الإسناد | بحسب نطاق الحق والطلب | نطاق الدعم الموثق |
| تنزيل مرفق وتصدير xlsx | لا | حق مستقل لكل عملية | بالحق الصريح والفلاتر. لا روابط عامة | نطاق الدعم الموثق |
| إعدادات وتبديل التصدير/الواتساب/Analytics | لا | إدارة | تفويض محدد حسب الفعل | ضمن نطاق الدعم |
| إدارة الموظفين والحقوق | لا | إنشاء وتعطيل وتفويض دون منح sysadmin من القائمة العادية | لا تصعيد أو تعطيل Owner | تهيئة واسترداد تقنيان منفصلان وموثقان |
| الاسترداد والسجل | لا | بدء إعادة تعيين لموظف إذا خُوّل وعرض السجل وفق السياسة | استرداد ذاتي أو صلاحية صريحة محدودة | مسار استرداد مستقل مع مراجعة المالك |

يتحقق الخادم من فعل وكائن ونطاق، بما فيه التنزيل والتصدير وكل عنصر من Bulk. تغيير الحقوق أو تعطيل الحساب يزيل الوصول التشغيلي. نطاق دعم sysadmin وشخصه وأسراره وإجراء الاسترداد يثبتون قبل التشغيل. سجل نشاط دون كلمات مرور أو أسرار أو نسخ حساسة غير لازمة. [البنود المتبقية](OPEN_ITEMS_REMAINING.md)

الدخول بالبريد أو الهاتف وكلمة مرور، دون MFA أو OTP للدخول ودون حد أو حظر محاولاته. الحماية المعتمدة للنماذج العامة تشمل Honeypot والتحقق وفحص التكرار بلا CAPTCHA. رصد الدخول لا يحظره. [المعمارية](ARCHITECTURE_ASSESSMENT.md) · [المخاطر](RISK_ASSESSMENT.md)
