## سجل اعتماد الواجهة

يسجل المالك إصدار Demo وطريقة الاستعراض وتاريخ العرض واسم ممثل العميل وأجهزة المراجعة. لكل ملاحظة يسجل الإجراء والنسخة التي عالجتها أو التأجيل المتفق عليه. قرار اعتماد النسخة وإذن بدء الـBackend يحتاجان توثيقًا صريحًا. الخانات الفارغة والصمت لا يفتحان البوابة.
