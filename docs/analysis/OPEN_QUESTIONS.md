# القرارات المفتوحة في Scenery 2.0

| الموضوع القديم | نتيجة المراجعة | القرار |
|---|---|---|
| استقلال صفحات الأعمال الخشبية ومن نحن والخصوصية والتصنيف | معتمدة. استكمال نص الخصوصية والمواد وبيانات الصفحات يظل في السجل التشغيلي | 01–04، 11، 38 |
| البحث، الحقول، المرفق وحالات المتابعة | معتمدة. الاسم والهاتف الدولي والدولة والوصف إلزامية في العام والبريد اختياري. صورة التصنيع المرجعية اختيارية، والصيغ والحدود التشغيلية مفتوحة | 05، 06، 08، 09، 33، 51، 53 |
| التصدير الدولي وإسناد الطلب | استقبال استفسار تصدير قابل للتعطيل مع بقاء القديم. إسناد موظف اختياري لكل طلب. تشغيل شحن فعلي خارج النطاق | 19، 34 |
| تعدد التصنيفات والحذف | تصنيف رئيسي إلزامي وإضافية اختيارية. الحذف بتحذير وموافقة مع بقاء المنتجات والوسائط. قاعدة نقل الأقسام الفرعية تفصل تقنيًا | 07، 22، 32 |
| CMS وSEO وFooter والإدارة | معتمدة ضمن قوالب ثابتة، مع FAQ وشهادات مصرح بها، حفظ مسودة وإصدارات وسلة وعمليات جماعية | 11، 12، 16–18، 20، 21، 45–48 |
| الأدوار والدخول والمراجعة | Owner وStaff وsysadmin تقني معلن. سياسة الدخول معتمدة باستثناء أمني. سجل النشاط معتمد. موافقة المخاطر والتعيين التشغيلي للحساب التقني معلقان | 29–31، 48 |
| إدارة الوسائط والبريد | رفع سياقي ومعالجة وتخزين معتمدة. المكتبة المركزية المتقدمة ولوحة البريد المتقدمة مؤجلتان. البريد الأساسي والاستعادة مطلوبان | 13، 24، 42، 53، 54 |
| الإحصائيات | أساسية وتجريبية وقابلة لتعطيل الواجهة وجمع المشاهدات. خيارات الجمع والخصوصية قبل تشغيلها الحقيقي | 50 |
| ترتيب التنفيذ | عرض Frontend Demo على العميل وإغلاق الملاحظات وموافقته الموثقة عند G3 قبل Backend. هذا إجراء قبول معلق وليس قرار نطاق يعاد طرحه | 56، 59، 60 |
| النسخ والإطلاق | اختيار الخطة مؤجل للحسم قبل الإطلاق. الاستعادة المجربة شرط تشغيل. قيم الاستضافة ومواعيد النسخ والاحتفاظ تحتاج اتفاقًا | 15، 55 |
