## الهوية وموافقة التشغيل

حقل واحد للبريد أو الهاتف الدولي الموحّد مع كلمة المرور. يمنع تضارب المعرفات بين حسابين. القرار 30 يقتضي غياب MFA وOTP للدخول وغياب تحديد أو حظر المحاولات. تفحص أي إعدادات افتراضية لإطار العمل أو البنية لاحقًا لضمان عدم إدخال حظر للدخول من وراء هذا القرار. تطبق كلمات مرور قوية وتجزئة وجلسات آمنة وHTTPS وCSRF وتفويض خادمي وسجل رصد دون حظر. استرداد 31 يستخدم رابط بريد محدود الصلاحية وأحادي الاستخدام. يبدأه مسؤول مخول للموظف دون معرفة كلمة مروره. 

sysadmin حساب صيانة ذو صلاحيات تقنية عليا، معلوم ومتفق عليه مع مالك المصنع، خارج قائمة الموظفين المعتادة، مع مسار تهيئة واسترداد منفصلين وسجل نشاط. يمنع التصعيد الذاتي ومنح الدور من الإدارة العادية. تبقى بيانات تهيئته وصاحبها وإجراء الاسترداد وحوكمة الدعم مفتوحة. الاستثناء يزيد تعرض الحسابات الإدارية للتخمين وحشو بيانات الاعتماد. الرصد يساعد على الاكتشاف وتبقى مخاطرة الاختراق قائمة. يطلب قبول تشغيلي واعٍ وموثق قبل G6. ## الحفظ والنشر والوسائط

يحفظ الاستفسار بمرجع ومصدر موثوق قبل إشعاره. يرتبط تخزين الملف الخاص بالحفظ، وتعالج الملفات المؤقتة اليتيمة وفق سياسة التشغيل. تنشأ نية إرسال قابلة لإعادة المحاولة، ويظل خيار Queue/Outbox والمصالحة وتشغيل العامل قرارًا تقنيًا حسب البيئة. يراجع اعتماد المستلم قبل المحاولة، ويسجل قبول مزود البريد منفصلًا عن الوصول الفعلي. يرسل ملخص ورابط محمي دون مرفق خاص عام. لا يغير عطل البريد نجاح الاستفسار المحفوظ. القرارات 31، 35، 53، 54 وALERT-001–004.

الرفع من المنتج أو المشروع أو المحتوى، مع مقاسات صور وتنسيقات ملائمة وبديل وأبعاد محجوزة وأولوية للصورة الرئيسية وتحميل كسول لما تحت الطية. الفيديو عند الطلب مع poster وبديل للـHero ودون تشغيل تلقائي بصوت. تعالج عمليات الحذف عبر المراجع المنشورة والمسودات والإصدارات والمحذوفات. إمكانية S3/R2 قابلية تقنية مستقبلية، واختيار تخزين خارجي قرار مستقل. القرارات 13، 24، 42، 47، 53.

الحفظ التلقائي يحدّث المسودة ويظهر حالته ويعالج استعادة فقد الشبكة. إذا استخدمت استعادة محلية تضبط حدود بياناتها ولا توضع فيها بيانات عملاء أو أسرار. ينشئ كل نشر إصدارًا. الاسترجاع ينشئ مسودة. سلة المحذوفات 30 يومًا افتراضيًا قابلة للتعديل. الجدولة والتنظيف النهائي يعتمدان سياسة الاحتفاظ والمراجع، والحذف النهائي يحتاج حقًا وتحذيرًا. القرارات 12، 45–48.

## الأداء وSEO والتشغيل

Metadata وOG وalt وslug وcanonical عند الحاجة وSchema وrobots وSitemap للمنشور. سعر مخفي أو مادة خاصة لا يظهران في HTML أو API عامة أو البيانات المنظمة أو مشاركة الرابط. النشر والإخفاء وتغيير السعر تتطلب اتساق النسخة المخبأة. دعم RTL والنصوص المختلطة وإتاحة الكيبورد والأزرار والتسميات وتقليل الحركة ضمن هدف WCAG 2.2 AA. أهداف القياس عند p75 هي LCP حتى 2.5 ثانية وCLS حتى 0.1 وINP حتى 200 مللي ثانية، ويثبت الأداء بالمحتوى والبيئة الفعليين. القرارات 16، 39، 41–44، 49، 56.
