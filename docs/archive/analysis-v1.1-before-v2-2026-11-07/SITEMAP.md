# خريطة صفحات Scenery

هذه خريطة وظيفية للمراجعة وليست تصميم واجهات أو تعريف Routes. المرجع S1 §§5–7 وS2 §§9–17؛ انظر [تعريف المصادر](SRS_REVIEW.md). رموز P/A داخلية للربط مع [المصفوفة](REQUIREMENTS_MATRIX.md) و[التدفقات](USER_FLOWS.md). جميع الشاشات المرئية بالعربية وRTL؛ اسم Scenery لا يترجم.

«مؤكدة وظيفيًا» تعني أن القدرة مطلوبة، لا أن عدد الشاشات أو تنظيمها النهائي اعتمد. حالات التحرير والمعاينة والتصنيف قد تتجمع داخل صفحة واحدة. المقترحات لا تصبح معتمدة بإدراجها هنا.

## حالات عابرة يجب تغطيتها لاحقًا

عدم وجود منتجات/نتائج، روابط غير موجودة أو محتوى أخفي، انتهاء جلسة أو معاينة، منع صلاحية، رفض ملف أو فشل معالجته، تعذر حفظ نموذج، نجاح الإرسال برقم مرجعي، تعطل فيديو مع صورة بديلة. هذه حالات تشغيل للصفحات وليست توسعة تجارية للنطاق.

لا صفحات لحساب عميل أو سلة أو طلب شراء أو دفع أو شحن أو لغة ثانية في هذه الخريطة. يتطلب تحويلها إلى تصاميم اعتماد Q-D وبوابة G2 في [الخطة](PROJECT_ROADMAP.md).
