# نظام تصميم Scenery

**مقترح G1 · مرجع مبدئي للقيم والأنماط المشتركة**

تستخدم الوثائق نفس رموز الألوان والخط واللمس وحالات التفاعل في الموقع والإدارة. الألوان والخطوط مقترحة للمراجعة على نموذج فعلي للرئيسية على الهاتف والكمبيوتر قبل الاعتماد النهائي. تختلف الأولوية البصرية باختلاف المهمة. صفحات المعرض تعتمد صورًا كبيرة وفراغًا بين الفصول، وشاشات الإدارة تحتاج مقارنة صفوف وتنفيذ أعمال متكررة. [الاتجاه](DESIGN_DIRECTION.md) · [الألوان والخطوط](TYPOGRAPHY_AND_COLORS.md)

## قواعد التكوين

- يبدأ كل قسم بعنوان أو صورة محورية واحدة. القوائم المقارِنة تحافظ على نسب الأغلفة ومحاذاة النص. الرئيسية وتفاصيل المشروع يمكن أن تجمع صورة كاملة مع لقطة قريبة تختلف عنها في الحجم. تتبع القراءة وترتيب الكيبورد منطق المحتوى نفسه.
- تسلسل المكونات هو رموز مشتركة، ثم عناصر التحكم (زر وحقل ورابط ووسم)، ثم مكونات مركبة (بطاقة ومعرض ونموذج وتنقل)، ثم قالب الصفحة. تتغير البيانات والظهور والترتيب ضمن القوالب المعتمدة، وتبقى مسافات العنوان والفصل داخل المكوّن.
- استخدم سطحًا مختلفًا أو فاصلًا بدل الظل المتكرر. الخلفية المحيطة بالحوار وحدها تستخدم تعتيمًا يفصل الطبقتين. تجنّب النص فوق مناطق مختلفة السطوع من الصورة.
- زر أساسي واحد في مجموعة قرارات واحدة. روابط مسطرة في المتن، وقيم قراءة مميزة بتسمية صريحة. الحالة المختارة تجمع علامة مرئية وتسمية برمجية تناسب نوع التحكم.

## الحركة والاستجابة

| التفاعل | الإيقاع المقترح | عند طلب تقليل الحركة |
|---|---|---|
| ضغط أو تغير لون زر | 120–160 مللي ثانية، تغيير لون وحد فقط | تحديث فوري |
| فتح درج أو حوار أو FAQ | 180–220 مللي ثانية، تغير محدود، دون ارتداد | إظهار فوري مع إدارة الفوكس نفسها |
| اختيار وسائط معرض | حتى 200 مللي ثانية على الصورة فقط مع بقاء الأبعاد | تبديل فوري بلا انزلاق |
| انتظار وحفظ | شكل ثابت في موضع المحتوى أو رسالة «جارٍ الحفظ» | شكل ثابت أيضًا، بلا وميض أو لمعان متحرك |

تبدأ فيديوهات المعارض بطلب صريح، وتتوقف عند إغلاق المعرض أو الانتقال منه. فيديو الافتتاح يدوي افتراضيًا، مع خيار تشغيل تلقائي صامت بعد تفعيله صراحةً وبشروط الأداء والوصول. تظل أدوات التشغيل والإيقاف واضحة، ويظهر الغلاف مع التشغيل اليدوي عند تفضيل تقليل الحركة. تجنّب الحركة المتكررة على النص أو تبديل موضع زر أثناء النقر. [سياسة فيديو الافتتاح](COMPONENT_SPECIFICATIONS.md#فيديو-الافتتاح)

## ضوابط الوصول والقبول

| ما يجب الحفاظ عليه | دليل الفحص لاحقًا |
|---|---|
| العربية لغة الصفحة وRTL اتجاهها، مع عناوين دلالية ومناطق تنقل ومحتوى وتذييل ورابط «تخطَّ إلى المحتوى» | شجرة وصول مفهومة، وتسلسل عناوين وتنقل منطقي في الموقع والإدارة |
| أزرار وروابط وحقول بتسميات ظاهرة أو أسماء وصول، وسلسلة فوكس كاملة. اجعل العنصر المركّز ظاهرًا بالكامل عند الرأس أو الأزرار المثبتة | Tab وShift+Tab وEnter وSpace، وEscape حيث ينطبق، وتجربة وصول ميدانية. تركيز مرئي مع الألوان القسرية |
| بديل للصورة المهمة، وبديل فارغ للزخرفة، وتعليقات نصية للفيديو ذي الصوت ومقابل للمعلومات البصرية اللازمة حسب معايير الوسائط | مراجعة المواد المعتمدة لكل صفحة. الصورة المصغرة تسمى بفعل أو وصف يميّزها، وأيقونة الزر لا تضاعف اسمه |
| بديل نقر واحد للسحب والتكبير، وبديل كيبورد لإعادة الترتيب، ورسالة حالة يفهمها قارئ الشاشة | تجربة معرض كامل دون إيماءات، وترتيب وسائط وأقسام دون سحب |
| إعادة تدفق عند عرض 320 بكسل CSS، وتكبير النص 200%، واختبار إعدادات تباعد النص دون قصّ | اختبار مستقل لإعادة التدفق والتكبير. الجداول ذات العلاقات البُعدية تُحصر في منطقتها مع بديل الهاتف حيث يمكن |
| ملخص أخطاء مع رسائل ملاصقة للحقول، وتقدم وحفظ ونجاح معلوم من النص. لون الحالة داعم | مقارنة الحالات المختارة والخاطئة والمعطلة وغير المتصلة في الوضع العادي وعالي التباين |
