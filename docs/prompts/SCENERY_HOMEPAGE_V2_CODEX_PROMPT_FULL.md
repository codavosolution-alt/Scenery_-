# 5. Typography System

يجب تحسين الخطوط العربية بشكل ملحوظ.

أريد Typography راقية ومتناسقة مع موقع أثاث فاخر.

يمكن تجربة **على الصفحة الرئيسية فقط** وبعد المقارنة مع الصورة:

- Noto Naskh Arabic للعناوين المميزة.
- IBM Plex Sans Arabic للنصوص وواجهات الاستخدام.

لكن يجب مقارنة النتيجة بصريًا مع الصورة المرجعية.

لا تستخدم الخطوط لمجرد اختلافها عن الخط الحالي.

### Typography Requirements

- عناوين واضحة وقوية.
- تباعد مناسب بين الأسطر.
- اختلاف مدروس في Font Weights.
- أحجام متجاوبة حسب الشاشة.
- تجنب العناوين الصغيرة جدًا.
- تجنب ازدحام النصوص.
- مراعاة الأرقام والنصوص الإنجليزية داخل RTL.

استخدم CSS clamp() للأحجام المتجاوبة عند الحاجة.

# 7. Image Assets & Content

الصور عنصر أساسي في نجاح التصميم.

### Mandatory Requirements

1. افحص الصور الموجودة داخل المشروع.
2. استخدم صورًا موجودة ومصرّحًا بها، سواء كانت تجريبية أو حقيقية معتمدة؛ لا تفترض أن صور الـDemo أعمال حقيقية للمصنع.
3. اختر الصور الأقرب لتكوين الصورة المرجعية.
4. حافظ على النسب الصحيحة للصور المتاحة، مع إدراك أنها أصول Demo مؤقتة.
5. لا تجعل استبدال الصور منخفضة الدقة شرطًا لإكمال هذا النموذج ما دامت تسمح بتقييم التصميم.
6. لا تستخدم صورًا ممدودة أو مشوهة.
7. لا تحول الصور إلى Backgrounds بطريقة تؤدي إلى قص غير مناسب.
8. حسّن تحميل الصور حسب الحاجة.
9. استخدم Lazy Loading للصور غير الظاهرة في بداية الصفحة.
10. تجنب Cumulative Layout Shift.

إذا لم تكن الصور المطابقة متاحة، استخدم الصور التجريبية الموجودة قدر الإمكان، وسجّل ما سيُستبدل لاحقًا دون تضييع الوقت في البحث عن مثالية الأصول.

# 8. Responsive Design

لا أريد تنفيذ تصميم الديسكتوب ثم تصغيره للموبايل بشكل عشوائي.

يجب تصميم تجربة Responsive مدروسة.

### Desktop

1440px and above:

- الحفاظ على التكوين البصري الكامل.
- صور كبيرة.
- مساحات مريحة.
- توزيع مطابق للمرجع قدر الإمكان.

### Laptop

1024px – 1439px:

- تقليل المسافات بشكل متوازن.
- الحفاظ على الـ Visual Hierarchy.
- منع تزاحم الصور والنصوص.

### Tablet

768px – 1023px:

- إعادة توزيع الـ Grids.
- ضبط أحجام الصور.
- تحسين القوائم.
- منع Overflow.

### Mobile

Below 768px:

- تصميم Mobile Layout مخصص.
- ترتيب الأقسام بطريقة منطقية.
- تكبير العناصر القابلة للمس.
- أحجام خطوط واضحة.
- أزرار سهلة الاستخدام.
- صور متجاوبة.
- مسافات مناسبة.

### Critical Mobile Requirements

- لا يوجد Horizontal Scrolling.
- لا يوجد Text Overflow.
- لا توجد صور مشوهة.
- لا توجد عناصر متداخلة.
- لا توجد Buttons صغيرة جدًا.
- لا توجد مسافات غير متناسقة.

اختبر أيضًا 320px و360px و375px و390px و430px و768px و1024px و1440px.
